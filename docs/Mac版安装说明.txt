AI 用量监控 · Mac 版 v1.6.8（macOS 12 及以上）
=====================================================

【选哪个包】
- Apple 芯片（M1/M2/M3/M4…）：AI用量监控-mac-arm64.zip
- Intel 芯片：AI用量监控-mac-x64.zip
  不确定的话：左上角  → 关于本机，看「芯片」那一行。

【安装】
1. 双击 zip 解压，把「AI Usage Monitor」拖进「应用程序」文件夹。
2. 第一次打开前（只需一次）：这个程序没有经过 Apple 公证，直接打开会提示「已损坏，无法打开」——文件并没有坏，点「取消」即可。
   打开「终端」，粘贴下面这行回车：
     xattr -cr "/Applications/AI Usage Monitor.app"
   如果还是打不开，再粘贴这一行（用 macOS 自带工具在本机重新签名）：
     codesign --force --deep --sign - "/Applications/AI Usage Monitor.app"
3. 打开后不会出现在程序坞里：屏幕右侧会出现黑色竖条，菜单栏右上角会出现它的小图标。

【使用】
- 显示 / 隐藏悬浮条：按 ⌃⌥⌘U（Control + Option + Command + U，设置里可以改），也可以点菜单栏图标。
- 竖条默认贴在屏幕右边缘。直接拖动它：靠近左右边缘松手就会吸附，拖到中间就变成自由悬浮的胶囊。
- 极简样式：鼠标停在图标上，弹出黑色小气泡（当前会话 / 所有模型、重置倒计时、已用百分比）；点一下可以固定。
- 详细样式：点击图标展开完整面板（5 小时额度、本周额度、本周已重置次数、其他额度、近 7 天趋势、套餐信息）。
- 切换样式、位置、刷新频率：菜单栏图标 → 展示样式 / 位置 / 设置…；也可以在竖条上点右键。
- 默认只显示已连接的 AI，没登录的自动隐藏；在设置里可以关掉这个选项。

【实时更新（v1.1 起为事件驱动）】
- 倒计时每秒走动。
- 一有使用就刷新：Claude Code / Codex / Gemini CLI 的会话文件、Claude 桌面版的本地数据一有写入，几秒内自动刷新对应 AI。
- 智能频率（默认开启）：最近 5 分钟在用或用量在变化时，按「刷新频率」查询（5 秒～5 分钟，默认 30 秒）；闲置时自动放慢到 2 分钟。
- Codex 优先读本地会话日志，基本不需要联网。
- 容错：偶尔一次网络失败不会报错，继续显示上次的数据并自动重试；连续失败 3 次才提示。Mac 休眠 / 锁屏时暂停，唤醒后自动恢复。

【各 AI 怎么连接】
- Claude：装了 Claude Code 会自动识别。第一次会弹出钥匙串授权，选「始终允许」。
  只用 Claude 桌面 App 或网页版的：设置 → Claude →「登录网页版」，在弹出的窗口里登录一次即可，之后会记住。
  也可以手动粘贴 claude.ai 的 sessionKey。
- Codex：自动读取 Codex CLI 的登录（~/.codex/auth.json）。
- Cursor：自动读取 Cursor 编辑器的登录（可能弹出钥匙串授权）；读不到时点「登录网页版」。
- Gemini CLI：自动读取 ~/.gemini/oauth_creds.json。
- GitHub Copilot：自动读取 Copilot 插件登录；或者在终端运行 gh auth token，把结果粘贴到设置里。
- Kimi Code、智谱 GLM：在设置里填写 API Key。

【网络】
默认跟随系统代理（ClashX、Surge 等开启「设置为系统代理」即可）。
也可以在 设置 → 网络代理 里手动填写，例如 127.0.0.1:7890。

【数据与日志】
所有设置、登录信息和历史只保存在本机：~/Library/Application Support/AI 用量监控/
出问题时：设置页底部点「查看日志」，把 log.txt 发给开发者即可。
