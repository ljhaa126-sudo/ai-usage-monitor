AI 用量监控 · Windows 版 v1.6.6（Windows 10 / 11，64 位）
============================================================

【安装】免安装，解压即用
1. 把 zip 解压到一个固定的位置，例如 D:\Apps\AI Usage Monitor\（解压后不要再移动或删除里面的文件）。
2. 双击「AI Usage Monitor.exe」运行。
3. 第一次运行时，Windows 可能弹出「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」。
   （程序没有购买代码签名证书，所以会有这个提示，只出现一次。）

升级：先在旧版托盘菜单里点「退出」，再用新版文件夹替换旧版（设置和登录会保留）。

【使用】
- 屏幕右边缘会出现黑色竖条；任务栏右下角的托盘区会出现小图标（可能收在「^」里），左键或右键点击都可以打开菜单。
- 拖动竖条：靠近屏幕左右边缘松手会吸附，拖到中间就变成自由悬浮的胶囊。竖条以外的透明区域不挡鼠标，可以正常点击下面的窗口。
- 极简样式：鼠标停在图标上，弹出黑色小气泡；点击可以固定。
- 详细样式：点击图标展开完整面板。切换方式：托盘菜单 → 展示样式，或者在竖条上点右键。
- 默认只显示已连接的 AI，没登录的自动隐藏；设置里可以关掉。

【连接各家 AI】（托盘菜单 → 设置…）
- Claude：装了 Claude Code 会自动识别。只用 Claude 桌面版或网页版的，点「登录网页版」，在弹出的窗口里登录一次即可（建议用邮箱登录）。
- Codex：自动读取 Codex CLI / 桌面版的登录。如果提示 HTTP 403（被 Cloudflare 拦截），会先用本机 Codex 会话日志显示用量；
  想恢复在线数据，在设置 → Codex 点「登录网页版」，登录 chatgpt.com 并通过一次验证即可。
- Cursor：自动读取 Cursor 编辑器的登录；读不到时点「登录网页版」。
- Gemini CLI、GitHub Copilot：自动读取；Copilot 读不到时，粘贴 gh auth token 的输出。
- Kimi Code、智谱 GLM：填写 API Key。

【实时更新】
倒计时每秒走动；Claude Code、Codex、Gemini CLI、Claude 桌面版一有新对话，几秒内就会自动刷新。
其他情况按「刷新频率」查询（默认 30 秒）；闲置时自动放慢到 2 分钟。
偶尔一次网络失败不会报错，会继续显示上次的数据并自动重试。

【任务提醒】
Codex / Claude Code 等任务完成或需要你处理时会弹出提醒；点击提醒会切回这个任务所在的窗口
（你发消息时所在的软件 → 会话来源：桌面版 / 编辑器 / 终端 → 默认顺序）。
登录了 Claude / ChatGPT 网页版的，网页版、桌面版、手机上的普通聊天回复完也会提醒。
提醒出现后对应图标会一直有脉冲光圈，鼠标移到图标上、点开提醒或切到那个窗口后消失。

【网络】
默认跟随 Windows 系统代理（Clash、v2rayN 打开「系统代理」即可）；也可以在设置里手动填写，例如 127.0.0.1:7890。

【开机自启】设置 → 登录时自动启动。

【数据与日志】
所有设置、登录信息和历史只保存在本机：%APPDATA%\AI 用量监控\
出问题时：设置页底部点「查看日志」，把 log.txt 发给开发者即可。
